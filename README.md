## 🚀 Sobre o Projeto

Este repositório contém o código-fonte do portfólio web de **Luiz Gustavo**, Desenvolvedor Full Stack & Backend.

- ⚡ **Arquitetura Leve**: Desenvolvido com HTML5 semântico, CSS3 moderno (Custom Properties, Glassmorphism, CSS Grid e Flexbox) e JavaScript Vanilla puro.
- 📱 **Totalmente Responsivo**: Otimizado para telas de smartphones, tablets, notebooks e monitores ultrawide.
- 🎨 **Design System Tokyo Night & Cyber Neon**: Paleta escura com gradientes dinâmicos, contrastes acessíveis e animações de digitação em tempo real.
- 🔗 **Integração**: Conexão com os repositórios reais do GitHub e com o site oficial [newfire.top](https://newfire.top).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3 Moderno**
- **JavaScript (ES6+)**
- **Font Awesome 6 & Google Fonts (Inter & Fira Code)**
- **GitHub Pages** para hospedagem gratuita de alta performance.
